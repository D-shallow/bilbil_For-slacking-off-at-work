# bilimini（摸鱼自用版）

* **右键菜单配置**
* **修复无边框拖拽失效问题**
* **减少白屏崩溃**
* **修复失效按键** esc返回、←后退、→前进、↑增加音量、↓减少音量、F1老板键、空格暂停/播放。

本代码有可能会随着bilbil的更新而失效。

---

## 运行环境
https://nodejs.org/zh-cn/download

## For Developers

```
$env:ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/"
npm install
```
```
npm start
```

## 使用electron-builder打包

```
npm run win64
npm run win32
npm run mac
```
